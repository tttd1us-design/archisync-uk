🏛️ ArchiSync UK - 글로벌 실시간 다국어 음성 통역 시스템 (영·일·중 ➔ 100% 한글)
===================================================================================

[1] 빠른 시작 방법
-----------------------------------------------------------------------------------
1. 압축을 해제한 폴더 내에서 [ ▶_1초_원클릭_설치_및_실행.bat ] 파일을 더블클릭합니다.
2. 바탕화면에 바로가기 아이콘이 생성되며 크롬 브라우저 앱 창으로 즉시 통역기가 뜹니다.
3. 평소에는 바탕화면의 [ ArchiSync UK 실시간통역 ] 아이콘 또는
   [ ▶_ArchiSync_오프라인_초고속_실행.bat ] 파일을 클릭하여 바로 실행하시면 됩니다.

[2] 주요 탑재 기능 및 특징
-----------------------------------------------------------------------------------
1. 0.03초 실시간 통역:
   - 영국/미국 영어, 일본어, 중국어 음성을 말하는 즉시 한국어로 실시간 번역
   - 250개 이상의 음향 왜곡 자동 복구 사전 내장 ("cotton wool" -> "curtain walling" 등)

2. 내 컴퓨터 자원(CPU / RAM / GPU) 하드웨어 가속:
   - GPU 비디오 카드 래스터화 가속으로 창 크기 조절/스크롤 시 60~120fps 부드러운 반응
   - CPU 점유율 0%, RAM 10MB 초경량 로컬 웹서버(server.ps1) 내장

3. 내 문서 자동 저장 (Real-Time Auto-Save):
   - 위치: 내 문서\ArchiSync_실시간통역
   - 대화가 진행될 때마다 텍스트 대본이 1초 만에 실시간으로 자동 업데이트 보관
   - 상단 [ 📂 내문서 폴더 ] 버튼 클릭 시 저장 폴더가 파일 탐색기로 즉시 열림

4. 무료 AI 모델 & AI 회의록:
   - 로그인 / 결제 / API 키 없이 100% 무료 AI 탑재
   - 상단 [ ⚡ AI 회의록 ] 버튼 클릭 시 3줄 요약, 핵심 의사결정, 조치사항 자동 생성

5. 칸 사이즈 & 글자 크기 자유 조절:
   - 좌측 원문 박스 / 우측 한글 통역 박스 각각 독립적으로 아래로 최대 1800px까지 확장 가능
   - 각 박스 헤더의 [ A- ] [ A+ ] 및 [ ↕+100 ] 버튼 제공
   - 하단 이전 대화 백업 아카이브 [ 📜 아카이브 ON/OFF ] 접기/펼치기 지원

6. 깃허브(GitHub) 원클릭 동기화:
   - [ ▶_GitHub_원클릭_동기화.bat ] 더블클릭 시 깃허브 원격 저장소와 자동 백업 동기화
